# Security Policy

## Responsible Disclosure

We take the security of this project seriously. If you discover a security vulnerability, we appreciate your help in disclosing it in a responsible manner.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to **security@imaxart.com**. This allows us to address the issue before it becomes publicly known and gives us the opportunity to release a fix.

## Response Time

We aim to acknowledge receipt of your report within **48 hours** and to provide an initial assessment of the report. We will keep you informed of our progress toward resolving the issue.

## What to Include

When reporting a vulnerability, please include:

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested fix (optional)

Thank you for helping keep this project and its users safe.
