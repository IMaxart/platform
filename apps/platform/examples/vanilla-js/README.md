# Vanilla JS Example

The simplest possible integration -- a single HTML file with no build step.

## Usage

1. Replace `analytics.yourdomain.com` in `index.html` with your analytics domain.
2. Open `index.html` in a browser.
3. Click the button and check the Network tab for requests to `/api/collect`.

## What it demonstrates

- SDK initialization via ESM import
- Custom event tracking on button click
- Zero build tooling required
