# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-02-23

### Added

- Privacy-first web analytics platform with self-hosted deployment
- Real-time dashboard with visitor stats, pages, events, sessions, and errors
- Bot detection and device exclusion system
- Feature flags with conditional targeting
- Lightweight tracking script (~5KB gzipped)
- `@imaxart/analytics` SDK package with React utilities
- Docker Compose deployment with PostgreSQL
- Multi-tenant subdomain-based architecture
- GDPR/RODO compliant by design (no cookies, hashed IPs)
- Internationalization (English and Polish)
- Light and dark mode
- Responsive design
