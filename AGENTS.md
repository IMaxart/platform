# AGENTS.md

## Forms

All forms use `@tanstack/react-form` (`useForm` + `form.Field`).
Never use `useState` to manage form state.

## Translations (i18n)

Every user-facing string must use paraglide: `m.key_name()` from `~/paraglide/messages`.
This includes labels, placeholders, error messages, button text, and status labels.
Raw API values (roles, statuses) must be mapped to translation keys before display.

## Quality gate

Run before every commit: `pnpm format`, `pnpm lint`, `pnpm type-check`.
Do not commit if any step fails.

## Cursor Cloud specific instructions

### Services overview

| Service | Port | How to start |
|---------|------|-------------|
| PostgreSQL 17 | 5432 | `sudo docker compose -f docker-compose.yml -f - up -d postgres <<< $'services:\n  postgres:\n    ports:\n      - "5432:5432"'` |
| Platform app | 3000 | `pnpm dev` (starts both apps via Turborepo) |
| Status app | 3001 | Started automatically alongside Platform by `pnpm dev` |

### Prerequisites before `pnpm dev`

1. **Docker must be running** — PostgreSQL runs in Docker. Start dockerd if needed: `sudo dockerd &>/tmp/dockerd.log &`
2. **PostgreSQL port 5432 must be exposed** — the production `docker-compose.yml` does not expose it to the host. Use the inline override shown above, or add a `docker-compose.override.yml` with ports.
3. **`.env` file** — copy from `.env.example` (`cp .env.example .env`). Defaults work for local dev.
4. **DB schema** — run `pnpm db:push` once after PostgreSQL is up.
5. **Admin user** — not auto-seeded in dev mode (only in production via `server.ts`). Seed manually:
   ```
   node --import tsx -e "const { seedAdmin } = await import('./packages/auth/src/seed-admin.js'); await seedAdmin(); process.exit(0)"
   ```
   Requires env vars: `ADMIN_EMAIL`, `ADMIN_NAME`, `ADMIN_PASSWORD`, `BETTER_AUTH_SECRET` (defaults in `.env.example`).

### Gotchas

- **`routeTree.gen.ts`** is auto-generated by TanStack Router when the Vite dev server starts. `pnpm type-check` will fail if you haven't run `pnpm dev` or `pnpm build` at least once.
- **esbuild build scripts** must be allowed. The `pnpm.onlyBuiltDependencies` field in root `package.json` includes `esbuild`. Without it, Vite will fail.
- **Status page** shows "Failed to load" when no status-page data exists — this is expected on a fresh DB.
- **Lint** produces ~1200 warnings (all from paraglide `m.*()` calls typed as unsafe). These are warnings, not errors — lint passes.
- Standard dev commands: see `README.md` and `CONTRIBUTING.md` for `pnpm dev`, `pnpm lint`, `pnpm test`, `pnpm build`, etc.
